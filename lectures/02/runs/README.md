# 実行記録

2026-11-02 に受講者アカウントの Google Colab / Tesla T4 で、AI 支援を利用して実際に実行した記録。講師の reference 結果は使用していない。

- `epochs20.ipynb`: 標準設定（20 エポック）の出力付きノートブック。
- `epochs10.ipynb`: 新規ランタイムで学習回数のみ 10 エポックに変更した出力付きノートブック。
- `epochs*_result.json`: 保存済みノートブックのセル 19 の要約、セル 12 の学習ログ、セル 17 の知識質問の表を転記したもの。
- `epochs*_eval_before.json` / `epochs*_eval_after.json`: セル 10 / 15 の表示表から転記した、全 21 問の生成原文と判定。モデルの出力を作り直したものではない。

`training.last_logged_loss` は最終ログ区間（10 ステップ分）の平均損失で、最後の単一バッチの損失ではない。`seconds_rounded` はノートブックの表示に合わせた秒単位の学習時間で、環境構築・モデル取得・評価の時間は含まない。

知識質問の「FAQ にある」列は元のコードが `q in gold`（評価用質問だけを収録）で判定しているため、学習用の対照質問「課題の提出期限はいつですか」も False と表示される。出力は原文のまま保存し、考察では実際の FAQ と照合して、これを根拠ありの対照として扱った。
